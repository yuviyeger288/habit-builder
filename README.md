# בניית הרגל — תוכנית פעולה

כלי שמנחה אדם, שאלה־שאלה, בבניית שיטה להרגל אחד — ובסוף מפיק תוכנית פעולה שאפשר להעתיק, להדפיס או לשמור כתמונה.

## קבצים

| קובץ | מה זה |
|---|---|
| `index.html` | הגרסה בלשון נקבה (ברירת המחדל) |
| `zachar.html` | הגרסה בלשון זכר |

בכל עמוד יש קישור לגרסה השנייה בפינה העליונה, כך שאותו לינק מתאים לכולם.

## עשר השאלות

1. מי אני רוצה להיות
2. מה ההרגל שיוכיח את זה
3. מה ההרגל מחליף
4. מה יפעיל אותי
5. הגרסה הקטנה לימים שקשה
6. מה מקל ומה מקשה
7. התגמול המיידי
8. איך מודדים
9. מה עושים אחרי שפספסתי
10. מתי מתחילים ומתי בודקים

לצד כל שאלה יש דוגמה ממולאת, וכפתור שפותח הסבר על מה השאלה בודקת ולמה היא קובעת אם ההרגל יחזיק.

## הערות טכניות

- קובץ HTML יחיד לכל גרסה, בלי שלב בנייה ובלי תלויות מקומיות.
- התשובות נשמרות בזיכרון הדפדפן בלבד ולא נשלחות לשום מקום. רענון הדף מאפס אותן.
- שמירה כתמונה משתמשת ב-html2canvas מ-CDN, ולכן דורשת חיבור לאינטרנט. שאר הכלי עובד גם בלי.
- בטלפון, "שמירה כתמונה" פותחת את תפריט השיתוף של המכשיר — משם אפשר לשמור לגלריה.

## עריכת התוכן

כל השאלות, ההסברים והדוגמאות יושבים במערך `Q` בתוך תגית ה-`script` בסוף הקובץ. כל שאלה היא אובייקט עם `t` (כותרת), `hint`, `ex` (דוגמאות), `why`, `explain` (ההסבר הנפתח) ו-`fields`.

שינוי בגרסה אחת צריך להיעשות גם בשנייה.
